# Rtx Dev - Portfolio Website

Portfolio website for **Rtx Dev**, a freelance web developer building modern websites, web apps, booking systems and e-commerce stores for businesses.

## Features

- Logo intro animation on page load
- Hero, Services, Work, Process, Pricing, FAQ and Contact sections
- 6 pricing plans (from Rs 12,000 + Rs 800/month)
- 50% advance payment shown on every plan
- WhatsApp contact form and floating WhatsApp button
- Light and dark mode, fully mobile friendly
- Animations with Motion

## Tech

TanStack Start, React 19, TypeScript, Tailwind CSS 4, Motion, built on Hercules.

## Where to edit

- Plans and prices: `src/lib/plans.ts`
- Name, logo, WhatsApp number, email: `src/lib/site.ts`
- Sections: `src/routes/-components/`
